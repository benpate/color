## Fluent Color Manipulations for Go

`color` is a small Go library for parsing colors and transforming them through a chainable, fluent API.

## Pull Requests Welcome

I'm trying to make color the best it can be, and your help is greatly appreciated. If you find a bug or have an idea for a new feature, please open an issue or submit a pull request. We're all in this together! 🎨
